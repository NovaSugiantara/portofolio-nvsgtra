# Nova Portfolio Static Prototype

A standalone professional portfolio prototype built with:

- Semantic HTML
- Tailwind CSS via CDN
- Lucide icons via CDN
- Small vanilla JavaScript interactions
- Intersection Observer reveal transitions
- Light and dark theme with local persistence
- Reduced motion support

## Run

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --directory nova-portfolio
```

Then visit `http://localhost:8080`.

## Notes

This is a static design prototype. CV download, contact form submission, blog, project detail routes, CMS, Supabase integration, and server-side rendering require application integration.
